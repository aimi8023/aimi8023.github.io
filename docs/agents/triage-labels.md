# Triage 标签

技能层使用五个标准的 triage 角色。本文件将这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 角色 | 标签名 | 含义 |
|------|--------|------|
| `needs-triage` | `needs-triage` | 维护者需要评估此 Issue |
| `needs-info` | `needs-info` | 等待提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，AI 可直接接管 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个 triage 角色（例如"打上 AFK-ready 标签"），使用上表中对应的标签字符串。

如需修改标签名，直接编辑右侧列即可。
