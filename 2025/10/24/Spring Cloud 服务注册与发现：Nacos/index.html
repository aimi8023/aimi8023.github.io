本项目依赖版本对应信息（请确认版本适配，否则可能出错）：

  • Spring boot版本:3.2.0
  • Spring cloud版本:2023.0.0
  • Spring cloud Alibaba版本:2023.0.1.0
  • mybatis-spring-boot-starter版本：3.0.3

Nacos是什么？

Nacos是目前 Spring Cloud 微服务体系中最推荐使用的服务注册、发现与配置中心。

本节主要讲解它的服务注册与发现的使用。
